Flappy Bird Game

HTML5 Canvas | CSS3 | JavaScript

A classic arcade-style game built with HTML JavaScript and CSS. Players control a bird that must navigate through a series of pipes by clicking or tapping to make the bird fly upward. The game features realistic collision detection, real-time score tracking that increases as the bird successfully passes through pipes, and smooth animations. When the bird collides with a pipe or the ground, the game ends and displays the final score. This project showcases game development logic, canvas rendering, and responsive event handling.
